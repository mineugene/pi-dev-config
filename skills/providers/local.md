# Local files

Provider for a project that documents a local-file tracker.

1. Write one file per ticket under `.scratch/<feature-slug>/issues/<NN>-<slug>.md`.
2. Number files from `01` in dependency order, blockers first.
3. Put each blocker as a stable reference in the ticket's `Blocked by` field.
4. Apply `ready-for-agent` only when project policy defines that label.
