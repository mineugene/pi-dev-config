# Wait What

Re-pitch the last message with all three elements:

1. State the context the last message assumed.
2. Write in plain language (ISO 24495-1): short sentences, one instruction per
   sentence, active voice, common words.
3. Use the project's domain terms from `GLOSSARY.md`. Follow `GLOSSARY-MAP.md`
   to the applicable context when the repository has more than one.
